# Quiet ordinary hover labels

Ordinary action names no longer open small hover popups across the main app,
Resource Map, Gathering and Fish Map. Their accessible names and actions remain
unchanged. Rich item artwork, source, location, map-point and reference details
remain available where the hover content itself carries useful information.

The change is presentation-only. It does not change calculations, navigation,
market requests, storage identity, saved-data schemas or personal-data paths.
The Fish companion keeps explicit item and equipment reference hints while its
navigation, profile, region, settlement and journal action labels stay quiet.

Verification covers the shared controls, retained accessibility names, approved
rich previews, package-owned action surfaces and the Fish static title-marker
policy. Map and Gathering regression suites confirm that native actions,
adaptive layouts and artwork remain intact.
