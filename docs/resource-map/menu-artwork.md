# Map menu artwork

The September 9, 2026 Home design uses original Iron Ore, Silver and Nampo worker-house artwork. Files are in `assets/images/menu_artwork/`; credits are in the adjacent licenses folder. Saved, checklist and other app commands use functional symbols.

Use 17 px labels, 36 px artwork and rows at least 52 px tall. Keep the shared glass surface, content-sized panels and readable large text. Material categories and item details use their actual game items.

An earlier generated parchment/checklist and journal design was rejected and removed from the bundle. It is not the current design. The retained Home artwork is not AI-generated.
