# Item window tabs

Opened and pinned item windows use attached **Recipe** and **Used for** tabs. Each tab keeps its own scroll position. Artwork joins the header; the content keeps a solid reading surface.

The header stays fixed. A single recipe keeps its action visible; multiple recipes keep separate actions. Copying, variants, dragging and closing still work.

Sakura uses the copper treatment. Other themes keep their colours. Passive artwork previews keep readable information without tabs that cannot be clicked.
