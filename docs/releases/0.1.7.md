# Black Spirit Life 0.1.7

> This is unofficial content which contains copyrighted materials and IP from
> Pearl Abyss, and is not official/endorsed content.

This release restores a five-destination app while tightening the boundary
between installed application files and personal data.

## What's new

- The title bar again exposes **Craft Planner**, **Resource Map**,
  **Gathering**, **Fishing**, and **Opportunities**.
- Gathering has an original native local workspace for mastery, loadout notes,
  and user-entered session records.
- Fishing has an original native local workspace for Fishing and Harpooning
  loadouts plus editable session records and results.
- The Craft Profile page now clearly identifies the one selected folder that
  owns all personal app data.
- The footer reports the installed application version instead of a stale
  version value retained in an older personal profile.

## Personal data and updates

- Planner data—including mastery, Fairy and weight settings, Value Pack,
  Rich Merchant's Ring, family fame, inventory, favorites and appearance—stays
  in `planner-state.json` under the selected personal-data folder.
- Gathering saves under `gathering/gathering-state.json`, and Fishing saves
  under `fishing/fishing-journal.json` in that same selected folder.
- A fresh folder starts with zero mastery, no saved loadouts and no sessions.
  The application does not automatically import Beta, legacy companion or
  another person's data.
- Before changing the folder or restarting for an update, the application
  freezes new personal-data edits and waits for accepted writes. The folder move
  validates Planner, Gathering and Fishing documents before switching.
- Installed 0.1.6 users receive the 0.1.7 delta package when it is smaller
  than the full package; a normal update keeps the selected personal-data
  folder in place.

## Public release boundary

No personal profile, session, loadout, journal, machine-specific path or cache
is bundled in this release. The private Beta's WebView/Python companion,
third-party Fish map caches, standalone Gathering datasets and media, and
legacy automatic import paths are not included. The two new workspaces contain
only original native application code and user-authored local records.
