# Black Spirit Life 0.1.4

> This is unofficial content which contains copyrighted materials and IP from
> Pearl Abyss, and is not official/endorsed content.

This update adds Cron Meal planning and makes ingredient alternatives easier
to use.

## What's new

- Added Seafood, Simple, and Exquisite Cron Meals.
- Added the current 1x and 10x Simple Cooking recipes.
- Added alternate recipe routes and higher-grade ingredient substitutions.
- Added Ancient Cron Spice and Nadia Rowen's Special Sauce.
- Added a small swap marker next to ingredients that can be changed.
- You can now click an interchangeable ingredient name in Craft Queue or Need
  First to choose another option. The lists update right away.
- Fixed ingredient names still keep their normal copy behavior.
- Removed the ingredient hover popup. Right-click still opens the map and
  planning menu.

Updates from 0.1.3 download, install, and restart through the update bar inside
the app. Your planner data and settings stay in place.

Black Spirit Life is a free, noncommercial, and unofficial Black Desert fan
tool. Because the installer is not code-signed yet, Windows may show an
unknown-publisher or SmartScreen warning.
