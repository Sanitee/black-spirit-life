# Black Spirit Life 0.1.10

> This is unofficial content which contains copyrighted materials and IP from
> Pearl Abyss, and is not official/endorsed content.

This release promotes the current approved Beta application to public Stable
while keeping every player's personal data in that player's selected local
folder, outside the installed application and release packages.

## What's new

- Opportunities has the approved balanced card typography across Crafting,
  Best Use, and Exchanges. Recipe names remain at least as prominent as their
  profit or value.
- Opportunities can sort supported Cooking, Alchemy, and Processing recipes by
  base EXP. Numeric EXP stays distinct from unknown EXP, and the saved choices
  include, hide, or exclusively show unknown entries.
- Unknown EXP entries use production-chain effort only for their relative
  ordering. This does not invent an EXP value or use personal mastery, market,
  inventory, or profit data as an EXP estimate.
- The Recipe Book includes the 17 September Twilight recovery routes: Heating
  one matching Causality Shardstone returns five Twilight of the End materials.
  Obsolete base-Apeiron Heating formulas are removed while valid item identities
  and reform recipes remain available.
- Planner ingredient previews and AFK weight coverage include the corrected
  substitution families used by current recipe definitions.

## Personal data and updates

- A fresh installation starts with zero mastery, no inventory or personal
  choices, no Fishing profiles or journal entries, no Gathering loadouts or
  sessions, no imports, and no credentials, cookies, or browser profile.
- Existing users continue to load Planner, Resource Map, Gathering, Fishing,
  Opportunities, Session Import, and generated browser state only from their
  own selected personal-data folder. Updating does not replace that folder.
- Installed 0.1.9 users receive the 0.1.9-to-0.1.10 delta package when it
  applies. Reinstalling is not required.

## Public release boundary

No publisher or player profile, mastery, inventory, Fairy or Merchant's Ring
choice, loadout, journal, session, saved import, receipt, credential, cookie,
generated browser profile, debug symbol, backup, or machine-specific personal
path is included. The same four privacy-bearing Gathering captures and six
source-only Resource Map research inputs excluded from 0.1.9 remain excluded.

The approved Beta's credited immutable reference content, interface, tools,
calculations, integrations, automation, and normal clean-profile defaults are
otherwise retained. Black Spirit Life is free, noncommercial and unofficial.
Black Desert and its game content belong to Pearl Abyss. Complete credits and
source-boundary notes are in `ASSET_SOURCES.md`, `THIRD_PARTY_NOTICES.md`, and
`docs/public-release-source-matrix.md`.
