# Black Spirit Life 0.1.3

> This is unofficial content which contains copyrighted materials and IP from
> Pearl Abyss, and is not official/endorsed content.

This is the first public Stable release of Black Spirit Life. It is built from
the single sanitized public source snapshot tagged `v0.1.3` and uses the
`win-x64-stable` update channel.

Black Spirit Life is a completely free, non-commercial and unofficial Black
Desert fan tool. There are no sales, subscriptions, donations or paid access.

Pearl Abyss owns the Black Desert game content and factual information used by
this fan project. BDO Codex, BDOLytics and the other sources listed in
`ASSET_SOURCES.md` are credited research, verification or retrieval
references. Black Spirit Life claims only its independently designed software,
selection, normalization, calculations, relationships and presentation; it
does not reproduce reference-site design, guides, commentary or annotations.

This release keeps the complete planner, resource and worker-node map, vendor
locations, item icons, NPC portraits, Edania Part II content, themed installer,
personal-data relocation, accessibility behavior and in-app delta updates.

Release behavior:

- The app starts with a clean profile and does not import Beta or older planner
  data. Inventory, masteries and other user inputs are stored as personal data.
- The About destination remains implemented but hidden until a later update.
- The app checks for updates once on every start. The bottom update bar remains
  hidden unless an update is available, downloading, ready or being applied.
- Public builds use the Stable channel and the GitHub Releases source at
  `https://github.com/Sanitee/black-spirit-life` without an embedded account
  token.

Download the attached `BlackSpiritLifeInstaller.exe`; GitHub's source-code ZIP
files are not the Windows installer. Because this first release is not code
signed, Windows may display an unfamiliar-publisher or SmartScreen warning.

Credits, source records, third-party notices and the correction/takedown route
are included in `ASSET_SOURCES.md`, `THIRD_PARTY_NOTICES.md` and the README.
