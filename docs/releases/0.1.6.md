# Black Spirit Life 0.1.6

> This is unofficial content which contains copyrighted materials and IP from
> Pearl Abyss, and is not official/endorsed content.

This release brings the reviewed planner, market, Resource Map and update
notice improvements from the latest approved Beta into the public Stable app.

## What's new

- A new **Opportunities** workspace compares selected crafting and exchange
  routes using current market information, with clear availability and cost
  details.
- Planner, Recipe Book and Inventory routing has broader catalog coverage,
  clearer acquisition notes and more consistent stock and profitability
  presentation.
- Shared market loading is paced, cached and recoverable so automatic checks
  remain responsive while offline use continues to work.
- The Resource Map has a more focused discovery layout, clearer material and
  worker-planning routes, improved compact-window behavior, adjustable UI
  opacity and refined house, storage and lodging tools.
- The in-app update notice is now a larger, clearer panel with a slow one-shot
  Sakura petal arrival effect. It labels delta updates and shows their saving
  compared with the full download.

## Personal data and updates

- No inventory, mastery values, plans, favorites, loadouts or sessions are
  bundled into the app.
- On first launch, 0.1.6 loads data only when this Stable app already has a
  profile in the selected local personal-data folder; otherwise it starts
  empty.
- The current folder is visible from the title bar and can be reviewed or
  changed under **Craft Planner > Data**.
- App files and personal data remain separate, so a normal 0.1.5 to 0.1.6
  update does not replace the profile folder.
- Installed 0.1.5 users receive a delta package when it is smaller than the
  full package; the updater falls back safely when a delta is not applicable.

## Public release boundary

The public release contains the reviewed Craft Planner, Resource Map and
Opportunities work. Private Fish Companion data, standalone Gathering
Companion media/data, Garmoth session-import material, personal profiles,
caches and machine-specific paths are not included.

Black Spirit Life is free, noncommercial and unofficial. Black Desert and its
