# Black Spirit Life 0.1.9

> This is unofficial content which contains copyrighted materials and IP from
> Pearl Abyss, and is not official/endorsed content.

This release promotes the complete approved Beta experience to public Stable
while keeping publisher and player activity data outside the installed app.
The version moves from public 0.1.7 to 0.1.9 so a withdrawn 0.1.8 candidate
cannot cause same-version update conflicts.

## What's new

- The five complete destinations are **Craft Planner**, **Resource Map**,
  **Gathering**, **Fish Map**, and **Opportunities**.
- **Gathering** includes its preparation, map, field-guide, loot, market,
  loadout, session, media-reference, and Bairog/BDO Workshop workflows.
- **Fish Map** includes map, haul, journal, statistics, screenshot recognition,
  and Fishing/Harpooning profiles. Its local service starts and stops with the
  app, and the reviewed reference snapshot is available without first
  downloading hundreds of megabytes after installation.
- Startup, retry, Alt+F4, taskbar close, and the title-bar close button now
  share one guarded Fish/WebView lifecycle, preventing native message-channel
  teardown while WebView creation or disposal is still running. Windows now
  routes close requests through that guard before Flutter can consume them;
  a request arriving before the native channel exists is retained and replayed
  as soon as the guarded path is available.
- Fish startup work is cooperatively cancellable. A dedicated native Windows
  job host owns the complete one-file service process tree before it can run,
  so an early boot failure is fully contained and may be retried once without
  leaving a hidden helper, locked journal, or occupied localhost port behind.
- **Session Import** retains the approved local review and app-managed Garmoth
  workflows. It requires the Microsoft .NET 8 Desktop Runtime for x64, which
  is not bundled with Black Spirit Life.
- The update notice uses the approved compact Sakura-petal treatment.

## Personal data and migration

- The selected personal-data folder is the durable root for Planner,
  Gathering, Fishing, Opportunities, Session Import, and generated browser
  state. It can be reviewed or changed from **Craft Planner > Craft Profile**.
- A fresh folder starts with zero mastery, no personal inventory or choices,
  no Fishing profiles or journal entries, no Gathering loadouts or sessions,
  no saved imports, and no credentials, cookies, or browser profile.
- Only user-created Fishing profiles and journal/haul/sale records are personal
  Fishing data. The immutable bundled Fishing map, species, location, price,
  recognition, and other reference databases and caches remain part of the
  installed product; they are not a player profile or journal.
- Existing Stable 0.1.7 Fishing profiles and journal records are migrated only
  from `fishing/fishing-journal.json` in the user's selected folder. Every valid
  v0.1.7 profile becomes an accessible current profile, including profiles with
  the old format's longer names or IDs, duplicate display names, blank/custom
  tool text, notes, and timestamps. A new migration does not invent an active
  selection; derived labels distinguish duplicate names without changing them.
- Stable 0.1.7 Fishing hauls remain visible in the journal as read-only
  aggregate records, including their fish totals, notes, and legacy received
  silver. The migration does not invent individual catches or sale records,
  and those legacy aggregates cannot be recalculated or sold again.
- Existing Stable 0.1.7 Gathering mastery, loadout notes, and sessions are
  migrated from `gathering/gathering-state.json` in the selected folder when a
  current Gathering store does not already exist. Mastery becomes the active
  confirmed preparation value used by Gathering calculations, loadout notes
  are shown read-only, and the previous sessions remain visible as non-editable
  history (with deletion still available) with their timestamp, duration,
  method, mastery, notes, and any non-empty location retained without
  fabricated loot, buffs, or pets. Their item total is labelled **Not
  recorded** because v0.1.7 did not store item
  counts. A blank legacy location is transparently labelled **Unspecified
  location** while its exact empty value and the Stable source remain archived
  locally.
- Both migrations leave the original Stable files unchanged and retain an
  exact local archive. An unrelated existing current-format store wins and is
  never merged with or overwritten by a legacy file. A recognized earlier
  unpublished Fishing migration is repaired in place without replaying its
  journal entries or replacing later profile edits. Migration does not import
  publisher/Beta data or upload the user's records.
- Close, update restart, and personal-data-folder moves freeze and flush
  supported feature state before the outer operation continues.

## Update size

Installed 0.1.7 users receive a 0.1.7-to-0.1.9 delta package when it applies.
The release gate requires that delta to be smaller than the full package, but
it is intentionally not tiny: this update adds the complete Fishing map,
reference snapshot, recognition icons, Gathering companion, and Session Import
payload that were not present in 0.1.7. Reinstalling is not required, and the
update does not replace the selected personal-data folder.

## Public release boundary

The release contains no publisher or player profile, mastery, inventory,
Fairy/ring choice, loadout, journal, session, saved import, receipt, credential,
cookie, generated WebView/browser profile, debug symbol, backup, or
publisher/player local-machine path. Four full-frame Gathering captures that
exposed real player/browser context are omitted; their public guide links and
credits remain. Six source-only private Resource Map research inputs are also
absent.

The approved Fish service retains its internal `Black-Spirit-Life/0.1.8` HTTP
client identifier. Stable 0.1.9 is the outer app/package version chosen after
the 0.1.8 candidate was withdrawn; that internal identifier neither controls
updates nor contains user data.

The approved Beta's credited reference content remains intact otherwise. This
includes the bundled FishyStuff-derived Fishing reference snapshot and PA item
art, Bairog/BDO Workshop reference data, Garmoth integration/catalog material,
and eleven credited Gathering guide images. The source files and in-app links
identify their origins. Black Spirit Life does not claim a third-party licence
or written permission where none is documented; the project owner expressly
approved this credited inclusion for the free, noncommercial release.

Black Spirit Life is free, noncommercial and unofficial. Black Desert and its
game content belong to Pearl Abyss. Complete credits and source-boundary notes
are in `ASSET_SOURCES.md`, `THIRD_PARTY_NOTICES.md`, and
`docs/public-release-source-matrix.md`.
