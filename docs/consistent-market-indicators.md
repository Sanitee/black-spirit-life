# Inventory and market badges

Use the same badges wherever the same information appears:

| Meaning | Display | Colour |
|---|---|---|
| Inventory | Game bag icon + amount | Based on owned amount |
| NPC vendor | Person icon + NPC | Vendor colour |
| Market stock | Market coin-bag icon + amount | Green above 0; red at 0; neutral when unknown |
| Preorders | Buy-cart icon + Orders + amount | Amber |

Orders never turn positive stock amber. Positive stock means some is listed; it does not mean there is enough for the whole batch. Unknown stock is not zero.

Shared badges cover normal, nested and pinned item views. Market tables use the same colours without adding duplicate badges. Prices, profit/loss and item grades keep their own meanings.

The user supplied the game icons. The cart originally means Buy in BDO; using it for Orders is this app's design choice. Keep Pearl Abyss credits. Do not add ordinary hover text; keep full accessibility labels.
