# Consistent market indicators — approved 5 November 2026

The user's option 2 is the marketplace coin bag for Stock and Buy cart for
Preorders. Original user-supplied game screenshots remain byte-exact in assets;
the shared widget selects the icon area and applies theme-coloured alpha at
render time. NPC uses the same bundled person artwork as the map vendor menu.
The inventory bag is available in this shared icon family for the separately
previewed Recipe Book design; this pass does not implement that page redesign.

Stock above zero is always green, zero is red, and unknown is neutral. Positive
preorders are independently amber, regardless of stock. Preorders never turn an
available card orange, and are not negative stock. Counts, freshness, prices,
profit/loss, eligibility and calculations are unchanged. An available stock count
does not promise enough items for an entire batch; existing shortage information
and purchasing calculations remain independent.

Apply through shared badges, not per-screen variants: Recipe Book lists/details,
item sources, recipe alternatives, hovered/pinned references, Planner and chooser,
Opportunities summary/details/substitutes/exchanges and hosted Gathering. Market
detail tables retain tabular quantities, using the same semantic colours rather
than adding duplicate pills. Standalone companion UI is a separate product;
hosted Gathering already injects the application's shared badge builder.

Availability card material follows the same stock-only tone. Planner availability
edges use green/red too. NPC remains a warm source marker, not marketplace stock.
Financial loss/demand calculations and item-quality colours are not availability
and are intentionally unchanged. This consistency rule is a prerequisite for
future UI changes, including every matching nested and passive display.

Artwork provenance: availability_marketplace.png and availability_buy_sell.png
are the user's marketplace screenshots supplied in this chat on 5 November 2026;
availability_inventory.png is their earlier Inventory screenshot. All are Pearl
Abyss game artwork, not generated substitutes. No personal game state is included.
The cart label in the source is Buy; using it for Preorders is the approved app
mapping, not a claim that it is a dedicated original preorder icon.
