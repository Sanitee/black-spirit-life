# Map package history

These are historical package changes, not app release numbers. Later designs and data reviews replace earlier ones. Early private-build distribution decisions are recorded in Git history; see the current source and credit documents for the public rules.

## 0.1.13 - 2026-08-12

- Added the named Citron Orchard focus and complete resource artwork.
- Hiding nodes also hides their connections and output artwork, while keeping saved choices.
- Fixed wheel zoom over map labels and simplified material source actions.

## 0.1.12 - 2026-08-04

- Smaller screenshot picker with region search, Anywhere / sea and Paste screenshot.
- Selecting a house highlights it without moving the map.

## 0.1.11 - 2026-08-03

- Scan several overlapping screenshots together; repeated matches improve confidence without overriding manual choices.
- Smoother panning in dense worker and housing views.

## 0.1.10 - 2026-08-03

- Added screenshot import with review before saving. Imports add records and preserve house-use choices.
- Worker-route costs include lodging and required houses.
- Added Recipe Book method labels and map actions.

## 0.1.9 - 2026-08-02

- Added map appearances paired with the main app theme.
- Theme changes keep the map position, search and planned network.

## 0.1.8 - 2026-08-02

- Improved text contrast over the map.
- Restored vendor details for Planner materials.

## 0.1.7 - 2026-08-02

- Planner worker actions open the map target editor with the material selected.
- Smaller network settings and filters that fit narrow windows.

## 0.1.6 - 2026-08-02

- Added material map actions and a saved worker target list.
- Added Copy my in-game setup; routes remain editable.
- Simplified source cards while keeping location evidence in the data.

## 0.1.5 - 2026-08-01

- Added 198 coastal gathering points, separate from Coral Stoneback Crabs.
- Added Marni Sniper Hunting as a named region, not invented spawn dots.
- Updated map colours and material categories.

## 0.1.4 - 2026-07-29

- Added shared-route CP planning and clearer changes to existing networks.
- Resolved 12 node links; five remained unlinked. Kept all 42 fish drying yards, with one unknown output.
- Added animal/herb locations, Log sources and Vedelona guidance.

## 0.1.3 - 2026-07-29

- Replaced the older graph with a 1,008-node snapshot; unknown links stayed unknown.
- Added source search, favourites, layers and worker-output artwork.

## 0.1.2 - 2026-07-28

- Added more historical points and a separate Rusalka candidate layer.
- Kept individual dots visible; added Gather/Worker filters and Planner shortages.

## 0.1.1 - 2026-07-28

- Removed unverified gathering circles.

- Stopped mapping Edania Golden Leaf Snake to generic Snake Meat.

## 0.1.0 - 2026-07-28

- First native map package: camera, search, tiles and Planner support.
- Added bounded caching, offline mode and cache clearing.
- Added the first generated dataset and SomethingLovely credits.
