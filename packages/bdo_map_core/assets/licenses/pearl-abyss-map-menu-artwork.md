# Original game artwork in map navigation

The map uses unmodified Black Desert item artwork owned by Pearl Abyss. These
assets identify materials, silver income, and housing; they are not recreated
or AI-generated icons. No additional frame, tint, or sharpening is applied.

- `iron_ore.webp`: Iron Ore, item 4001. Unchanged copy of the bundled Gathering
  item icon (`assets/icons/items/4001.webp`).
- `silver.webp`: Silver, item 1. Unchanged copy of the bundled Gathering item
  icon (`assets/icons/items/1.webp`).
- `house.webp`: Nampo worker lodging house artwork, copied unchanged from the
  reviewed September 3, 2026 client extraction:
  `new_icon/09_cash/02_housing/inhouse_cash_workman_nampo_01.webp`.

These game assets remain subject to the same private-app licensing constraints
as the other bundled Pearl Abyss icons. This notice does not grant new rights.
